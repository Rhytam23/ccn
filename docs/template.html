GPU-accelerated hybrid QEC decoding

A hybrid pipeline: a pre-decoder clears the easy, local part of the syndrome; only the residual reaches the global decoder (MWPM for the surface code, BP+OSD for qLDPC and for the experimental Ising pipeline). Every number below is measured by the benchmark harness in this repo; rows where the GPU is slower than the CPU are shown on purpose.

Reproduce

git clone <repo> && cd <repo>
python -m venv .venv && . .venv/bin/activate
# Install the PyTorch build for this CUDA host first.
pip install -e ".[dev]"
python -m pytest -q
python scripts/run_benchmarks.py --profile full --device cuda --surface-modes none zero local --reps 5 --tag my-run
python scripts/make_report.py

Or open notebooks/01_run_benchmarks_colab.ipynb in Google Colab (free T4 GPU).
